# Koenigsegg-AMV
Esse é o meu segundo repositório! Nele estão contidos diversos códigos novos que aprendi e que vou passar a usar em futuros projetos.

🎬 Custom Video Player - JS OOP

Este é um player de vídeo customizado desenvolvido para fins de estudo, focado em manipulação de mídia via JavaScript, Programação Orientada a Objetos (Classes) e estilização de controles de interface.

🚀 Funcionalidades

O player conta com controles personalizados que substituem os padrões do navegador:

1. Controle de Reprodução: Play e Pause.
2. Velocidade Dinâmica: Toggle (alternância) entre 1x e 2x de velocidade.
3. Gerenciamento de Áudio: Slider de volume e botão Mute (Toggle).
4. Navegação Temporal: Botões para avançar ou voltar 10 segundos.
5. Barra de Progresso: Barra interativa que acompanha o tempo do vídeo e permite saltar para pontos específicos.
6. Display de Tempo: Cronômetro formatado (MM:SS) atualizado em tempo real.
7. 
🛠️ Tecnologias Utilizadas

- HTML5: Estrutura e API de vídeo.
- CSS3: Estilização da interface e controles.
- JavaScript (ES6+): Lógica funcional utilizando Classes (POO) e manipulação de DOM.
   
🧠 Aprendizados Adquiridos

Neste projeto, foram explorados conceitos fundamentais de desenvolvimento Web:

1. Programação Orientada a Objetos: Organização de código utilizando class e constructor.
2. Lógica de Toggle: Implementação de alternância de estados (Mudo/Som, Velocidade 1x/2x).
3. Eventos de Mídia: Uso de eventos como timeupdate para sincronizar a interface com o vídeo.
4. Matemática Aplicada: Uso de operadores como Resto da Divisão (%) e métodos Math.floor e Math.max para formatação de tempo e cálculos de porcentagem.
5. Manipulação de DOM: Captura de inputs do tipo range para controle de volume e progresso.

📂 Como executar o projeto

1. Clone ou baixe este repositório.
2. Certifique-se de ter um arquivo de vídeo (ex: Koenigsegg.mp4) na mesma pasta.
3. Abra o arquivo index.html em seu navegador preferido.
